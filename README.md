# レジ袋いりません。 / ASOBEAT

スマートフォン向け縦画面・2D剛体物理バランスゲームです。GitHub Pages でそのまま公開できる構成です。

## プレイ

`index.html` をブラウザで開くか、HTTPサーバー上で公開してください。スマートフォンは横スワイプ、PCはマウスの左右ドラッグ（キーボード左右キーも補助操作として利用可能）で主人公を動かします。落下商品を両手で支え、商品が地面に触れたら終了です。

## フォルダ

- `index.html` : メイン画面
- `css/style.css` : レスポンシブUI
- `js/physics.js` : 外部依存のない凸形状2D剛体物理、固定120Hz、摩擦・回転・衝突
- `js/game.js` : 20商品、商品生成、物理状態、カメラ、Canvas描画
- `js/input.js` : ポインター操作・バックグラウンド制御
- `js/effects.js` : パーティクル・画面揺れ・スコア演出
- `js/audio.js` : Web Audio によるオリジナルの効果音・ループBGM
- `js/storage.js` : ローカル自己ベスト・名前・ランキング・設定
- `js/main.js` : 画面遷移とUI制御

## GitHub Pages 公開

1. 新しい公開リポジトリを作成（例：`rejibukuro_iranai`）。
2. `index.html` と `css/`、`js/` フォルダをそのままアップロード。
3. Settings > Pages > Deploy from a branch > `main` / `(root)`。
4. 公開URL例：`https://asobeatapps-ops.github.io/rejibukuro_iranai/`（リポジトリ名が上記の場合）。

## 広告

結果画面に広告用の表示枠を設けていますが、AdSense広告コードは**まだ設置していません**。サイトの承認・広告フォーマットの確認後に、規約に沿って設定してください。ゲーム中の広告表示はありません。

## 保存・プライバシー

ローカルランキング、プレイヤー名、設定は同一ブラウザのlocalStorageにのみ保存します。オンライン送信・オンラインランキングはありません。ブラウザデータを削除すると記録も消えます。

## 物理設定

- ワールド単位：1単位 ≒ 1m
- 120Hz固定ステップ / 10回衝突インパルス反復
- 重力：9.8m/s²相当
- 支持面：0.8m
- キャッチ：支持接触0.30秒継続
- 安定：相対速度0.15m/s以下、角速度8°/秒以下を0.35秒継続
- 投下高：現在の積み荷の最上部から1.5m
- 投下位置：商品ごとに固定、横初速0、初期角速度0
- サイズ：前商品より面積を必ず拡大、序盤12%、中盤6%、以降2%
- カメラズーム下限：初期倍率の50%

後半の商品では現実的な操作難度が非常に高くなる可能性があります。物理システムはカスタムの凸多角形衝突モデルで、Matter.jsそのものではありません。公開前に実機でゲームバランス・当たり判定・稀なすり抜けを検証してください。
